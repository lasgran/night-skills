# Distinctive frontend design

## Goal
Sites that look intentional for THIS brief — not AI-template defaults.

## Before pixels
Name the subject, audience, and primary job of the page. Visual choices come from materials/vernacular of that world (felt toy brand ≠ fintech dashboard).

## Avoid default AI tells
- Cream + terracotta serif kit
- Acid-green on near-black with no reason
- Identical rounded SaaS cards + soft grey shadows everywhere
- ALL-CAPS eyebrows on every heading, middle-dot meta strings, arrow after every link

## Craft
- Hero opens with the most characteristic thing (type, image, 3D, interaction) — pick one
- One or two type families with a clear scale; headline type is part of the design
- Motion: one orchestrated moment > scatter fade-ups on every section
- Structure encodes meaning (numbered steps only if content is a sequence)

## Process
Plan aesthetic direction → review against brief → build with real copy → critique for template tells → iterate

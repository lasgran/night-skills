# Landing conversion

## Default section order
1. Hero — clear value + one primary CTA above the fold
2. Social proof band
3. Problem → solution (not a feature dump)
4. Visual showcase (demo / 3D / screenshot) with benefit-first copy
5. Pricing if relevant (one recommended tier)
6. FAQ / objections
7. Final CTA restating the outcome

## CTA rules
- One primary CTA language/color site-wide
- Outcome wording (“Começar grátis”) not “Enviar”
- Secondary CTAs visually quieter

## Friction
- Price / no-card clarity near signup when true
- Named testimonials beat anonymous quotes
- Hero media must not tank LCP (conversion is a perf metric)

## Anti-patterns
- Must scroll to understand the product
- Competing primary CTAs in one viewport
- Vague “Fale conosco” as only path for self-serve

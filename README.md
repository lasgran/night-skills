# Skills do Night

Coleção de skills (receitas de trabalho) em Markdown, para outro agente de IA aprender e reutilizar.

## Como usar (para o agente)

- Cada pasta tem um `SKILL.md`: o topo (frontmatter) traz `name` e `description`, e o corpo é a receita.
- A `description` diz **quando** usar a skill. Leia a lista abaixo, escolha a que combina com a tarefa e siga o `SKILL.md` dela antes de começar.
- As skills `getting-started-*` são roteiros de primeira conversa com um novo dono.
